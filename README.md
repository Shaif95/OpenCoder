# OpenCoder Agent: An Open-Source, Privacy-First Autonomous Coding Agent for Commodity Hardware

## Vision
Build the first truly capable open-source coding agent that runs entirely on developers' desktops using quantized open-weight models.

## Research Contributions

### 1. Small-model software engineering
Make 7B–14B quantized models perform like much larger coding models.

### 2. Local context management
* Efficient repository indexing
* Hierarchical memory
* Context compression
* Long-context retrieval
